# अंक-दूरदर्शी — मोबाइल नंबर न्यूमरोलॉजी (v2.0)

100% ऑफलाइन, इंस्टॉल करने योग्य Progressive Web App (PWA) जो किसी भी 10-अंकीय मोबाइल नंबर का
पूरा न्यूमरोलॉजी विश्लेषण करता है — मूलांक/भाग्यांक अनुकूलता, 10-अंकीय पदानुक्रम, मित्र-शत्रु
जोड़े, Lo Shu ग्रिड भरपाई, स्कोर व अंतिम निर्णय।

## प्रोजेक्ट संरचना

```
ank-doordarshi/
├── index.html          # मुख्य पेज (मार्कअप)
├── manifest.json        # PWA मैनिफेस्ट (इंस्टॉल करने योग्य ऐप)
├── sw.js                 # Service Worker — ऑफलाइन कैशिंग
├── css/
│   └── style.css         # पूरी स्टाइलिंग
├── js/
│   └── app.js             # पूरा एप्लिकेशन लॉजिक (कोई बदलाव नहीं, मूल लॉजिक सुरक्षित)
├── icons/
│   ├── icon.svg
│   ├── icon-192.png
│   ├── icon-512.png
│   └── apple-touch-icon.png
├── package.json
└── README.md
```

## चलाना (Run Locally)

किसी भी स्थानीय सर्वर से खोलें (Service Worker के लिए `file://` नहीं, `http://localhost` चाहिए):

```bash
# Node.js इंस्टॉल है तो
npx serve .
# या
npx live-server

# Python इंस्टॉल है तो
python3 -m http.server 5173
```

फिर ब्राउज़र में `http://localhost:5173` खोलें।

## मोबाइल पर ऐप की तरह इंस्टॉल करना

1. उपरोक्त किसी भी तरीके से साइट को होस्ट करें (Netlify, Vercel, GitHub Pages, या अपना सर्वर —
   HTTPS ज़रूरी है, इंस्टॉल के लिए)।
2. मोबाइल क्रोम/सफारी में साइट खोलें।
3. Android: मेनू → "Add to Home screen" / iOS: Share → "Add to Home Screen"।
4. ऐप अब होम स्क्रीन आइकॉन से खुलेगा, फुल-स्क्रीन, बिना ब्राउज़र बार के — और इंटरनेट के बिना भी काम करेगा।

## तैनाती (Deployment)

यह एक स्टैटिक साइट है — बिना बिल्ड-स्टेप के किसी भी स्टैटिक होस्ट पर तैनात की जा सकती है:

- **Netlify / Vercel**: पूरे फोल्डर को ड्रैग-ड्रॉप करें या Git से कनेक्ट करें। Build command खाली रखें, publish directory `.`
- **GitHub Pages**: रिपॉज़िटरी में पुश करें → Settings → Pages → branch चुनें।
- **कोई भी स्टैटिक होस्ट / cPanel**: पूरा फोल्डर अपलोड करें।

HTTPS ज़रूरी है ताकि Service Worker (ऑफलाइन मोड) व "Add to Home Screen" काम करें।

## विशेषताएं

- 100% क्लाइंट-साइड — कोई डेटा सर्वर पर नहीं जाता, कोई बैकएंड नहीं चाहिए
- ऑफलाइन काम करता है (Service Worker कैशिंग)
- होम स्क्रीन पर इंस्टॉल करने योग्य (PWA मैनिफेस्ट)
- मोबाइल-फर्स्ट, टच-ऑप्टिमाइज़्ड UI, हैप्टिक फीडबैक (vibrate)
- रिपोर्ट कॉपी / प्रिंट-टू-PDF / नेटिव शेयर सपोर्ट
- प्रिंट-फ्रेंडली स्टाइलशीट (`@media print`)

## अपडेट करते समय

`js/app.js` में विश्लेषण-लॉजिक (गणना, मित्र-शत्रु टेबल, टेक्स्ट-कंटेंट) है — बदलाव यहीं करें।
`css/style.css` में सारी थीम/स्टाइलिंग है। जब भी फ़ाइलें बदलें, `sw.js` में `CACHE_NAME` का
वर्ज़न नंबर बढ़ाएं (जैसे `v1.0.1`) ताकि यूज़र्स को पुराना कैश्ड वर्ज़न न मिले।
